# 🎵 Gamified Metronome

A modern, interactive metronome application built with Vue 3, Vite, and Vuetify. This project combines traditional metronome functionality with gamification elements to make rhythm practice more engaging and fun.

## ✨ Features

- **Interactive Metronome**: Precise timing with customizable BPM settings
- **Gamified Experience**: Engaging elements to motivate practice sessions
- **Modern UI**: Clean, responsive design powered by Vuetify
- **Vue 3 Composition API**: Built with the latest Vue 3 features using `<script setup>` syntax

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd gamified-metronome
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## 🛠️ Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
